# Gothic II: NK — Zwiadowca

Solucja do modyfikacji **Zwiadowca**, oparta na materiale VIN-a i Racera75. Wiki korzysta z Docusaurusa.

## Uruchamianie

Wymagane Node.js 24 i pnpm 11.19.0.

~~~sh
pnpm install --frozen-lockfile
pnpm start
~~~

Podgląd: `http://localhost:3000`. Kontrola: `pnpm check`.

## Edycja

Zadania są w `docs/solucja/`, porady w `docs/porady.md`, a strona główna w `docs/README.mdx`. Zwykłą treść zapisujemy w `.md`. Ilustracje są w `docs/solucja/ilustracje/`. Nazwy zadań mają H2 i stałe kotwice `{#id}`. Poprawki zgłaszaj przez Pull Request.
